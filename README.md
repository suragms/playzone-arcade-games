# 🎮 PlayZone | Ultimate Online Arcade Gaming Hub

> A modern, high-performance web-based arcade gaming platform built with React 19, Vite, Tailwind CSS v4, and Convex backend.

🌐 **Live Demo**: [https://playzone-arcade-hub.vercel.app](https://playzone-arcade-hub.vercel.app)

---

## 📌 Project Overview

**PlayZone** is an interactive, full-stack arcade gaming web application designed to bring classic retro games into a sleek, modern, glassmorphic UI. The platform includes mini-games such as **Snake** and **Whack-A-Mole**, complete with live leaderboards, real-time user authentication, customizable themes, dynamic animations, and sound effects.

* **Project Type**: Paid Project / Self Works
* **Developer & Architect**: Surag (Founder of HexaStack Solutions)

---

## ✨ Features

- 🕹️ **Interactive Games**: Classic arcade games like Snake, Whack-A-Mole, and interactive mini-challenges.
- 🏆 **Global Leaderboards**: Real-time high scores and statistics tracking powered by Convex DB.
- 🔒 **User Authentication**: Secure guest and Email OTP authentication via Convex Auth.
- 🎨 **Modern UI/UX**: Built with Shadcn UI, Framer Motion animations, and Tailwind CSS v4.
- 📱 **Fully Responsive**: Mobile-first adaptive layout for smooth gameplay on desktop, tablet, and mobile.
- 🔊 **Sound Engine**: Custom sound FX and visual feedback for interactive gameplay.

## 🚀 Setup & Installation Instructions

Follow these steps to run PlayZone locally:

### 1. Prerequisites
Ensure you have **Node.js (v18+)** and **npm** or **bun** installed on your system.

### 2. Clone the Repository
```bash
git clone https://github.com/suragms/playzone-arcade-games.git
cd playzone-arcade-games
```

### 3. Install Dependencies
```bash
npm install
# or
bun install
```

### 4. Configure Environment Variables
Create a `.env` file in the root directory:
```env
VITE_CONVEX_URL=https://placeholder.convex.cloud
CONVEX_SITE_URL=http://localhost:5173
```

### 5. Run the Development Server
```bash
npm run dev
# or
bun dev
```
Open your browser and navigate to `http://localhost:5173`.

### 6. Build for Production
```bash
npm run build
```
